Dominó Score es un marcador digital para partidas de dominó. Sirve para anotar los puntos de cada mano, ver quién va ganando y llevar el historial y las estadísticas, todo desde el teléfono y sin internet. Tiene dos modos:
Modo mesas: varias mesas a la vez, con jugadores o parejas.
Modo enfrentamiento: muchos jugadores, cada uno con su columna de historial, y relevos cuando se para uno y entra otro.
También tiene teclado numérico para anotar rápido, historial con las anotaciones eliminadas tachadas, deshacer y estadísticas por jugador.
